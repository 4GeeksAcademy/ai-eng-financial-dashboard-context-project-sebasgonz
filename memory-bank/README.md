# Banco de memoria del proyecto

Este directorio separa el contexto persistente por propósito; los archivos enlazados documentan lo observado en el repositorio y no sustituyen a la implementación como fuente de verdad.

- [projectbrief.md](projectbrief.md): propósito del dashboard, flujo de usuario y límites del producto.
- [techContext.md](techContext.md): lenguajes, frameworks, dependencias, arquitectura y ejecución.
- [progress.md](progress.md): capacidades observadas, validaciones históricas, gaps y decisiones pendientes.

Las pruebas citadas mantienen su fecha y procedencia en [verification.md](../verification.md); no se presentan como reejecutadas durante la edición de esta memoria.
